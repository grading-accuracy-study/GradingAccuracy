# Validate Metadata JSON

This function validates a JSON file that stores metadata about the
assignment, its course and rubric items. The contents of the saved JSON
file can be printed out.

## Usage

``` r
validate_metadata_json(file = "./metadata.json", verbose = F)
```

## Arguments

- file:

  file path where metadata.json should be saved

- verbose:

  if course information should be printed out
