# Calculate Proportion of Identical Scores

This function calculates the proportion of identical scores between two
Gradescope evaluation dataframes

## Usage

``` r
isp(eval1, eval2, rubric_matching_list)
```

## Arguments

- eval1:

  first dataframe of Gradescope evaluations

- eval2:

  second dataframe of Gradescope evaluations

- rubric_matching_list:

  this is only to check if the comparison is valid

## Value

a single proportion
